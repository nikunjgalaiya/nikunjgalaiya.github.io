# Nikunj Galaiya portfolio

Source for https://nikunjgalaiya.github.io/ .

## Contents

Buildless HTML, CSS and JavaScript portfolio with an interactive stock decision tool, retail reporting dashboard, browser-only quotation workflow, MSc dissertation overview and CV download.

## Run locally

Use `python -m http.server 8000` from this directory, then open http://127.0.0.1:8000 . No package installation or build step is required.

## Hosting

GitHub Pages serves the root directory of the main branch. `.nojekyll` preserves static files. The quote demo stores fictional state in browser memory; the downloadable Python/SQLite implementation runs locally.

## Evidence

The two independent case studies use synthetic data. Their source packages include requirements, business rules and tests. The dissertation description is based on the author’s MSc report; no clinical use or production deployment is claimed.
